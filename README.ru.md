# Открытый протокол NeuroBridge (NB-SPEC-v1)

**Открытый, независимый от модели протокол исполнения команд и долговременной памяти, связывающий любую облачную или локальную нейросеть с ОС Windows — без API-ключей и привязки к облакам.**

## Зачем нужен NeuroBridge?
- **Работает с любой нейросетью**: ChatGPT, Claude, Gemini, DeepSeek или локальные модели через обычный веб-чат без оплаты API.
- **Долговременная память**: автоматически подклеивает законы ядра, документацию проекта и открытые тикеты ошибок в каждый отчёт (`<id>_отчёт.txt`).
- **Безопасная автоматизация**: проверяет синтаксис PowerShell через AST до запуска, изолирует проекты мьютексами и FIFO-очередями.
- **100% портативность**: автономная структура папок с экспортом в один клик и бесшовным переносом памяти в новый чат (`start_new_chat.txt`).

## Быстрый старт
1. Запустите `Start_NeuroBridge.cmd` для старта диспетчера **`NeuroBridgeTray.exe`** в системном трее.
2. Прикрепите файл старта нового чата в диалог с нейросетью.
3. Нажмите кнопку **Копировать** под блоком PowerShell от ИИ — `watcher_go.ps1` выполнит его сам (или нажмите **Alt+E**).
4. Вставьте готовый файл отчёта из буфера обмена (**Ctrl+V**) обратно в чат.

## Архитектура
- `_Core\Docs\` — законы ядра (`CORE_RULES.md`), архитектура (`CORE_ARCHITECTURE.md`), дизайн-стандарт и база ошибок.
- `_Core\Runner\` — конвейер выполнения (`watcher_go.ps1`, `hotkey_go.ps1`, `go.ps1`, `auto_footer.ps1`, `snapshot_knowledge.ps1`).
- `_Core\TrayApp\` — исходники диспетчера в трее (`Program.cs`) и портативный бинарник (`NeuroBridgeTray.exe`).
- `Projects\<id>\` — изолированные рабочие проекты со своей документацией (`02_Docs\`) и персональными отчётами.
