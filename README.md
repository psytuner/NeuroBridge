# NeuroBridge Open Protocol (NB-SPEC-v1)

**Open, model-agnostic execution and persistent memory protocol linking any Web or Local LLM with Windows OS — zero API keys, zero cloud lock-in.**

## Why NeuroBridge?
- **Works with any LLM**: ChatGPT, Claude, Gemini, DeepSeek, or local models via web UI — no API billing required.
- **Persistent Context**: Automatically injects core rules, project docs, and open error tickets into every report (`<id>_report.txt`).
- **Safe Local Automation**: Validates PowerShell AST syntax before execution, enforces per-project mutex locks and FIFO queues.
- **100% Portable**: Self-contained folder structure with one-click ZIP export and seamless session handoff (`старт_нового_чата.txt`).

## Quick Start
1. Run `Start_NeuroBridge.cmd` to launch **`NeuroBridgeTray.exe`** in the system tray.
2. Attach the startup snapshot to a new LLM chat session.
3. Copy any PowerShell block generated by the LLM — `watcher_go.ps1` executes it automatically (or press **Alt+E**).
4. Paste the resulting report file (`Ctrl+V`) back into the chat.

## Architecture
- `_Core\Docs\` — Core rules (`CORE_RULES.md`), architecture (`CORE_ARCHITECTURE.md`), UI standard, and error base.
- `_Core\Runner\` — Execution pipeline (`watcher_go.ps1`, `hotkey_go.ps1`, `go.ps1`, `auto_footer.ps1`, `snapshot_knowledge.ps1`).
- `_Core\TrayApp\` — System tray manager source (`Program.cs`) and portable binary (`NeuroBridgeTray.exe`).
- `Projects\<id>\` — Isolated workspaces with dedicated documentation (`02_Docs\`) and reports.
